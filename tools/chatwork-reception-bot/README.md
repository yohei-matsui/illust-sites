# Chatwork 受付Bot(動画制作)

「株式会社TendAi×松井くんチーム」ルームへの動画制作依頼を事務アカウントが自動で受け付け、
制作グループの森岡さんへ共有し、月別の案件台帳に起票する Google Apps Script です。
台帳は既存の納品・請求台帳(月別タブ、1動画1行)の列構成をそのまま引き継いでいます。

## 導入手順

1. 案件台帳にするGoogleスプレッドシートを開き、「拡張機能 > Apps Script」を開く
2. `Code.gs` の内容をそのまま貼り付けて保存
3. 左メニュー「プロジェクトの設定」>「スクリプト プロパティ」に追加
   - `CW_TOKEN` : 受付アカウント(相宮 美桜。旧「有流悟 理澄 -事務-」と同一)の Chatwork APIトークン
4. 関数 `setupSheet` を実行(初回は権限の承認が出る)
   - 「マスタ」「テンプレート(非表示)」「今月のタブ(YYYYMM)」「集計」「_bot(非表示)」が作られる
5. `testParse` を実行し、「実行ログ」で直近の依頼が正しく拾えているか確認
6. `installTrigger` を実行(5分おきに `poll` が動く)
7. 一次返信は初期状態では **OFF** です(台帳への起票と担当者の反映だけ動きます)。
   依頼者への返信と制作グループへの共有を始めるときに `startReplies` を実行してください。止めるときは `stopReplies`。
8. 提出予定日のリマインドも初期状態では **OFF** です。始めるときに `startReminders`、止めるときは `stopReminders` を実行してください。

## 台帳の列(月別タブ)

| 列 | 項目 | 記入 |
|---|---|---|
| A | No. | 自動 |
| B | 依頼日 | Bot |
| C | 提出予定日 | 担当者(「中止」と入れると中止扱い) |
| D | 依頼者 | Bot |
| E | 案件名 | Bot |
| F | 動画名(シナリオNo.など) | Bot が「動画1..n」を仮入力、担当者が書き換え |
| G | 動画尺 | 担当者 |
| H | 担当者 | 森岡さん |
| I | YouTube URL | 担当者(入れるとステータスが納品済になる) |
| J | 依頼メッセージ | Bot(Chatworkリンク、案件の先頭行のみ) |
| K | 備考 | Bot が希望納期とフォーマットを入れる。以降は自由記入 |
| L | ステータス | 自動(未割り振り / 制作中 / 納品済 / 中止) |

- 依頼1件につき「制作本数」ぶんの行が入ります(3本なら3行)
- 行は依頼日の月のタブに入ります
- 提出予定日を過ぎてURLが空の行は薄赤、担当者が空の行は担当者セルが黄色になります
- 「集計」タブに月ごとの本数とステータス内訳が出ます
- 既存の月タブの列や数式を直したいときは、そのタブを開いて `applyLayoutToActiveSheet` を実行すると、データを残したまま数式・入力規則・条件付き書式を揃え直せます
- `backfillThisMonth` を実行すると、今月の過去の依頼をChatworkに投稿せずにシートへ起票できます(動作確認用)

## Botの動作

| 投稿 | 依頼者への返信 | 制作グループ | 台帳 |
|---|---|---|---|
| 依頼テンプレ(「□ 案件名」を含む) | 10〜15分後に一次返信 | 森岡さんへ共有 | 本数ぶん追加 |
| 事務宛(To)の修正・確認依頼 | 10〜15分後に定型返信 | 森岡さんへ共有 | なし |
| 事務宛(To)の納期・担当の問い合わせ | なし | 森岡さんへメンション | なし |
| 事務宛(To)のその他の連絡 | 10〜15分後に「追ってご連絡します」 | 森岡さんへ共有 | なし |
| 共有メッセージへの返信(日付1つ) | 10〜15分後に初稿スケジュールを連絡 | なし | 担当者・提出予定日を反映 |
| 共有メッセージへの返信(日付が複数) | なし | 森岡さんへメンション | なし |
| 「(F)初稿提出 / (F)修正稿提出」(制作グループ) | なし | なし | URL・動画名・動画尺を更新 |
| 「初稿/修正稿ご確認のお願い」(TendAiルーム) | なし | なし | URL・動画名・動画尺を更新 |
| 事務宛(To)でない投稿(依頼テンプレ以外) | なし | なし | なし |

- 0:00〜8:59 の投稿への返信は当日 9:00〜9:20
- ポーリングは5分おきなので、実際の投稿タイミングは上記から最大5分ずれます
- 曜日は問わない
- 社内メンバー(事務・森岡・松井・牛嶋)の投稿には反応しない
- トリガー導入前の投稿は無視する(初回実行時刻を起点にする)

## 担当者からの期日報告

Bot が制作グループに出す共有メッセージには、次の一文が入ります。

> この投稿への返信で、担当の方から「先方提出日」をご報告ください(例: 9/14)。
> そのまま依頼者へ初稿スケジュールとしてお伝えします。

- 返信に日付が**1つ**あれば、それを先方提出日として扱います。返信した人が担当者になります。
- 台帳の担当者と提出予定日を埋めたうえで、10〜15分後に依頼者へ初稿スケジュールを送ります。
- 日付が**複数**あるときは判断せず、森岡さんにメンションして人に任せます。
- 社内メンバー(森岡・牛嶋・松井)の返信だけが対象です。
- 1案件につき1回だけ処理します。後から日付を変える場合は、人が直接連絡してください。

**運用上の注意**: 担当者が報告するのは社内提出日ではなく**先方提出日**です。確認と修正の時間(実績では2日)を見込んだ日付を報告してください。

## 提出の検知(URL・動画尺の自動更新)

担当者が制作グループに投稿する「(F)初稿提出 / (F)修正稿提出」を読み取り、台帳を更新します。

```
(F)修正稿提出
□坂本桃太郎さん
初心者・未経験軸
https://youtube.com/shorts/MDnWqbt5hu8
□ プロマネ
https://82.gigafile.nu/...
□ 動画データ
https://82.gigafile.nu/...
```

- **YouTube URL は毎回上書き**します。修正稿が出るたびに更新されるので、台帳のURLは常に最新版を指します。
- **動画名**は、初稿の時点で仮の「動画1」から実際のタイトル(例: 初心者・未経験軸)に書き換えます。以降の修正稿はそのタイトルで同じ行に戻ります。
- **動画尺**は YouTube の実尺を取得し、マスタの区分に切り上げて入れます。

### 動画尺の取得について

YouTube の内部API(InnerTube)の WEB クライアントに問い合わせて実尺を取り、マスタの区分に切り上げます。
**APIキーも設定も不要**で、クォータも消費しません。限定公開の動画でも尺を取得できます。

`testVideoLength('https://youtube.com/shorts/xxxx')` を実行すると、実尺と区分をログで確認できます。

万一この経路が使えなくなった場合に備え、拡張サービス「YouTube Data API v3」が有効ならそちらも試す作りにしてあります(通常は不要)。
どちらでも取得できない場合は動画尺を空のままにし、URL と動画名だけを更新します。

### TendAiルームへの直接納品も拾います

制作グループを通さず TendAiルームへ直接投稿された「初稿/修正稿ご確認のお願い」も検知して、同じように台帳を更新します。
森岡さんのように自分で制作して直接納品する場合でも、シートが最新になります。

```
[code]修正稿ご確認のお願い
8/14ご依頼　ACTION4さま[/code]
...
[info]
01｜無償活動を、子どもの食の未来につながる事業へ
https://youtube.com/shorts/cFk25OZuevs
02｜ニッチな個人活動が、企業・団体と仕事をする事業へ
https://youtube.com/shorts/WhvTvjAmV8g
[hr]
https://5.gigafile.nu/...
[/info]
```

- 1通に複数本入っていても、タイトルとURLの対をすべて拾います
- 社内メンバー(相宮・森岡・松井・牛嶋)の投稿だけが対象です
- 依頼者が納品メッセージを引用して返信した場合、引用部分は無視します
- ギガファイル便のリンクは動画として扱いません
- 制作グループの提出と両方が動いた場合は、**時系列で後のほう**が残ります

### 過去分の取り込み

- `backfillSubmissions`: 制作グループの過去の提出を台帳に反映
- `backfillDeliveries`: TendAiルームの過去の納品を台帳に反映

どちらも Chatwork への投稿はしません。

## 提出予定日のリマインド

毎日**正午**に、担当者ごとに To を分けて制作グループへ投稿します。

```
牛嶋さん
お疲れさまです。
【本日が先方提出日】
・坂本桃太郎さん 2本

【明日が先方提出日】
・橋谷のり子さん 3本

提出済みでしたら、この投稿は読み飛ばしてください🙇
```

- 対象は提出予定日が**本日**または**明日**の行
- YouTube URL が入っている行(納品済)、提出予定日が「中止」の行、担当者が空の行は対象外
- 該当がない担当者には送りません
- 今月と前月のタブを見ます
- 1日1回だけ送ります(正午より前のポーリングでは送らない、正午を過ぎた最初のポーリングで送る)
- `previewReminders` を実行すると、いま送るとどうなるかを実行ログで確認できます(投稿はしません)

## 設定を変える場所

- ルームID・アカウントID・文面: `Code.gs` 冒頭の `CONFIG` と `msg*` 関数
- 返信までの分数・朝の返信時刻・ポーリング間隔・リマインド時刻: `CONFIG.REPLY_MIN_MINUTES` / `MORNING_WINDOW_MINUTES` / `POLL_MINUTES` / `REMIND_HOUR`
  (`POLL_MINUTES` を変えたら `installTrigger` を実行し直してください)
- 担当者・ジャンル・動画尺のプルダウンと料金表: 「マスタ」シート

## 止め方

- 返信だけ止める: `stopReplies` を実行(台帳の起票・担当者反映は続く)
- リマインドだけ止める: `stopReminders` を実行
- すべて止める: Apps Script の「トリガー」から `poll` のトリガーを削除する
