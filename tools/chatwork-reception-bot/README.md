# Chatwork 受付Bot(動画制作)

「株式会社TendAi×松井くんチーム」ルームへの動画制作依頼を事務アカウントが自動で受け付け、
制作グループの森岡さんへ共有し、案件シートに起票する Google Apps Script です。

## 導入手順

1. 案件シート用のGoogleスプレッドシートを開き、「拡張機能 > Apps Script」を開く
2. `Code.gs` の内容をそのまま貼り付けて保存
3. 左メニュー「プロジェクトの設定」>「スクリプト プロパティ」に追加
   - `CW_TOKEN` : 事務アカウント(有流悟 理澄 -事務-)の Chatwork APIトークン
4. エディタ上部の関数選択で `setupSheet` を選んで実行(初回は権限の承認が出る)
   - 「案件シート」「マスタ」「_bot(非表示)」が作られる
5. `testParse` を実行し、「実行ログ」で直近の依頼が正しく拾えているか確認
6. `installTrigger` を実行(1分おきに `poll` が動く)

## 動作

| 投稿 | 依頼者への返信 | 制作グループ | 案件シート |
|---|---|---|---|
| 依頼テンプレ(「□ 案件名」を含む) | 10〜15分後に一次返信 | 森岡さんへ共有 | 1行追加 |
| 事務宛(To)の修正・確認依頼 | 10〜15分後に定型返信 | 森岡さんへ共有 | なし |
| 事務宛(To)の納期・担当の問い合わせ | なし | 森岡さんへメンション | なし |
| それ以外 | なし | なし | なし |

- 0:00〜8:59 の投稿への返信は当日 9:00〜9:05
- 曜日は問わない
- 社内メンバー(事務・森岡・松井・牛嶋)の投稿には反応しない
- トリガー導入前の投稿は無視する(初回実行時刻を起点にする)

## 設定を変える場所

- ルームID・アカウントID・文面: `Code.gs` 冒頭の `CONFIG` と `msg*` 関数
- 返信までの分数・朝の返信時刻: `CONFIG.REPLY_MIN_MINUTES` ほか
- 担当者・フォーマットのプルダウン: 「マスタ」シート

## 止め方

Apps Script の「トリガー」から `poll` のトリガーを削除する。
