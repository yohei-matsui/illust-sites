# Chatwork 受付Bot(動画制作)

「株式会社TendAi×松井くんチーム」ルームへの動画制作依頼を事務アカウントが自動で受け付け、
制作グループの森岡さんへ共有し、月別の案件台帳に起票する Google Apps Script です。
台帳は既存の納品・請求台帳(月別タブ、1動画1行)の列構成をそのまま引き継いでいます。

## 導入手順

1. 案件台帳にするGoogleスプレッドシートを開き、「拡張機能 > Apps Script」を開く
2. `Code.gs` の内容をそのまま貼り付けて保存
3. 左メニュー「プロジェクトの設定」>「スクリプト プロパティ」に追加
   - `CW_TOKEN` : 事務アカウント(有流悟 理澄 -事務-)の Chatwork APIトークン
4. 関数 `setupSheet` を実行(初回は権限の承認が出る)
   - 「マスタ」「テンプレート(非表示)」「今月のタブ(YYYYMM)」「集計」「_bot(非表示)」が作られる
5. `testParse` を実行し、「実行ログ」で直近の依頼が正しく拾えているか確認
6. `installTrigger` を実行(1分おきに `poll` が動く)

## 台帳の列(月別タブ)

| 列 | 項目 | 記入 |
|---|---|---|
| A | No. | 自動 |
| B | 依頼日 | Bot |
| C | 提出日 | 担当者(「中止」と入れると中止扱い) |
| D | 依頼者 | Bot |
| E | 案件名 | Bot |
| F | 動画名(シナリオNo.など) | Bot が「動画1..n」を仮入力、担当者が書き換え |
| G | ジャンル(属人/非属人/差し替え/AI) | 担当者(差し替え案件はBotが仮入力) |
| H | 動画尺 | 担当者 |
| I | 料金 | 自動(マスタの料金表: ジャンル×動画尺)。例外は上書き |
| J | YouTube URL | 担当者 |
| K | 依頼メッセージ | Bot(Chatworkリンク、案件の先頭行のみ) |
| L | 担当者 | 森岡さん |
| M | 納期 | Bot が希望納期を仮入力、森岡さんが確定 |
| N | 修正回数 | 担当者 |
| O | 備考 | 自由記入(Botはフォーマットを入れる) |
| P | ステータス | 自動(未割り振り / 制作中 / 納品済 / 中止) |

- 依頼1件につき「制作本数」ぶんの行が入ります(3本なら3行)
- 行は依頼日の月のタブに入ります。請求は提出日基準なので、月をまたいだ行は提出月のタブへ移してください
- 納期を過ぎて未提出の行は薄赤、担当者が空の行は担当者セルが黄色になります
- 「集計」タブに月ごとの本数・料金合計・未割り振り数・納品済数が出ます

## Botの動作

| 投稿 | 依頼者への返信 | 制作グループ | 台帳 |
|---|---|---|---|
| 依頼テンプレ(「□ 案件名」を含む) | 10〜15分後に一次返信 | 森岡さんへ共有 | 本数ぶん追加 |
| 事務宛(To)の修正・確認依頼 | 10〜15分後に定型返信 | 森岡さんへ共有 | なし |
| 事務宛(To)の納期・担当の問い合わせ | なし | 森岡さんへメンション | なし |
| それ以外 | なし | なし | なし |

- 0:00〜8:59 の投稿への返信は当日 9:00〜9:05
- 曜日は問わない
- 社内メンバー(事務・森岡・松井・牛嶋)の投稿には反応しない
- トリガー導入前の投稿は無視する(初回実行時刻を起点にする)

## 設定を変える場所

- ルームID・アカウントID・文面: `Code.gs` 冒頭の `CONFIG` と `msg*` 関数
- 返信までの分数・朝の返信時刻: `CONFIG.REPLY_MIN_MINUTES` ほか
- 担当者・ジャンル・動画尺のプルダウンと料金表: 「マスタ」シート

## 止め方

Apps Script の「トリガー」から `poll` のトリガーを削除する。
