# プロフィール文(素材弁護士)

X bioは160字上限。元文の4要素(界隈の今/民度が悪くてクスクス/1ポストでまとめ/書き出し休憩)を維持し、人格+読者への小馬鹿(図星型)を反映する。

## 採用候補

### 案A(推奨)
動画編集界隈の事件とトレンドに、1ポストで判決を下しています。民度の悪い祭りほどよく笑える — ええ、君が今見ているその祭りです。書き出し休憩と"称して"Xを眺める諸君に、笑いと使える判断をひとつずつ。フォローの礼は不要です。どうせ言わないでしょうから。

### 案B(法廷モチーフ・短)
動画編集界隈の事件・トレンドを1ポストで裁く非公式法廷。傍聴席は、書き出し休憩のふりをしてXへ逃げてきた君の指定席です。民度の低い祭りを笑い、使える判断を置いて閉廷します。せいぜい学んで帰りなさい。

### 案C(挑発最大)
界隈の"今"? よろしい、まとめて差し上げます。どうせ君は、書き出し待ちの3分を勉強に使えた試しがないでしょう。ならばここで。事件とトレンドを1ポスト・判決付き、民度は保証しませんが実利は保証します。感謝は不要、リポストで結構。

## 設計メモ
- 「わかりやすくまとめます」(謙虚)は人格と矛盾するため「判決を下す」へ
- 笑い担当に見られないよう「使える判断を置く」を必ず入れる(商品は判断、の宣言)
- 「書き出し休憩」は元文の資産。人格語彙に変換しつつ、小馬鹿の突き所として使う
- 読者への小馬鹿は必ず「図星」型にする(サボり中である事実、民度の一部である事実)。的外れな悪口は毒ではなくただの失礼(persona.md「火力」参照)
- 締めの「どうせ言わないでしょうから」は型Aサンプルの台詞と統一
