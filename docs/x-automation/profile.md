# プロフィール文(素材弁護士)

X bioは160字上限。元文の4要素(界隈の今/民度が悪くてクスクス/1ポストでまとめ/書き出し休憩)を維持したまま人格を反映する。

## 採用候補

### 案A(推奨)
動画編集界隈の事件とトレンドに、1ポストで判決を下しています。民度の悪い祭りほどよく笑える。笑ったあとに使える判断をひとつ置いていくのが流儀です。開廷時間は、君の書き出し休憩。フォローの礼は不要です。どうせ言わないでしょうから。

### 案B(法廷モチーフ全振り・短)
動画編集界隈の事件・トレンドを1ポストで裁く非公式法廷。民度の低い祭りをクスクス笑い、最後に使える判断を置いて閉廷します。開廷は君の書き出し休憩に合わせて。

### 案C(挑発強め)
界隈の"今"を知りたい? よろしい、私がまとめて差し上げます。動画編集界隈の事件からトレンドまで、1ポスト・判決付き。民度は保証しませんが、笑いと実利は保証します。書き出し休憩のお供にどうぞ。感謝は不要、リポストで結構。

## 設計メモ
- 「わかりやすくまとめます」(謙虚)は人格と矛盾するため「判決を下す」へ
- 笑い担当に見られないよう「使える判断を置く」を必ず入れる(商品は判断、の宣言)
- 「書き出し休憩」は元文の資産。人格語彙に変換して「開廷時間は君の書き出し休憩」
- 締めの「フォローの礼は不要です。どうせ言わないでしょうから」は型Aサンプルの台詞と統一
