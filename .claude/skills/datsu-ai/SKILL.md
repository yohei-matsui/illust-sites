# 脱AI文体パス(datsu-ai)

書き上げたドラフトに対して、以下のチェックを**全文に対して機械的に**かけ、該当箇所を書き直す。
キャラクター固有の演出(法廷口調・誇張・反語)は削らない。削るのはAIの癖だけ。

## 検出パターン(AI臭チェックリスト)

### 1. 説明癖・言い直し癖
- 直前に示した事実を抽象語で言い直す(「〜が…を証明している」「〜を物語っている」)
- 読者が読み取れることを文章化する。**構図が伝わるなら言うな**
- 「つまり」「要するに」で始まる総括

### 2. 論文語彙・翻訳調
- 「〜の必要性」「〜の重要性」「価値を示す」「本質的に」「まさに」
- 「〜と言えるでしょう」「〜ではないでしょうか」の婉曲疑問
- 「AはBではなく、Cです」の教科書的対比構文の連発

### 3. 二段構えの捻り
- 前言を打ち消して裏返すオチ(「冗談です。……いや、半分は本気ですが」)
- 括弧書きの自己ツッコミ
- オチは一段。**一番強い一言だけ残して他を捨てる**

### 4. 過剰な整い
- 全文が同じ長さ・同じ語尾で並ぶ(です/です/です)
- 三項並列の乱用(「早く、安く、正確に」)
- 完璧な起承転結。**どこか一箇所、突き放して終わる方が人間らしい**

### 5. 記号・修飾の癖
- 「」による強調の乱発(1投稿2回まで)
- 三点リーダ・ダーシの多用(1投稿1回まで)
- 感嘆符の複数使用

## 書き直しの原則

1. 抽象名詞を具体に落とす(「編集の必要性を証明」→「編集者がいないとこうなる」)
2. 一文を短くし、長短のリズムを不均等にする
3. 断定で切る。緩衝材(「〜かなと」「〜だったりします」)は全削除
4. 口に出して読み、芝居がかった台詞として成立するかで最終判定する
5. 修正後、削った文字数を報告する。**増えていたら失敗**

## このプロジェクトでの適用先

- `docs/x-automation/samples.md` の全ポスト文面
- 生成パイプラインでは品質フィルタの最終段でこのチェックを実行する
